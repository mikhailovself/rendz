# rendz web

Веб-версия rendz для Vercel: лента музыкальных клипов (YouTube), листание свайпом/колесом/стрелками.

## Деплой
1. Залей папку в GitHub-репозиторий.
2. vercel.com → Add New → Project → выбери репозиторий → Deploy (настройки по умолчанию).

## Как устроено
- `public/` — интерфейс (статика). Настройки, лайки и дизлайки хранятся в браузере (localStorage).
- `api/clip.py` — функция, которая выбирает трек (чарты Apple Music + список легенд) и находит клип на YouTube.
- Видео играет через встроенный плеер YouTube — прямые ссылки yt-dlp привязаны к IP и с сервера не работают.

## Отличия от десктопной версии
- Только YouTube (VK, Rutube, Dailymotion убраны). Если у клипа запрещено встраивание — он пропускается.
- Страна артиста: вместо MusicBrainz — чарт страны + кириллица (в режиме «Только СНГ» берутся треки с кириллицей).
- Браузер запускает видео со звуком только после первого клика/нажатия клавиши.
